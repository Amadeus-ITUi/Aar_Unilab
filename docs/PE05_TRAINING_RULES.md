此前的 100 轮迁移验证和最近保存至 500 轮的正式训练都是具体 run，不能把它们的轮数
当作默认预算。`pe01_gait` 短训实验曾覆盖为 4096 环境、100 轮、每 25 轮保存/评估，

启动器实际解析后的配置可先用 `bash tools/train.sh pe05_gait_fixed --dry-run` 检查；
环境变量还能覆盖线程数，因此表中 32/1 是未额外设置环境变量时的值。

### 1.3 一个策略步的实际执行顺序

1. 用 10 帧历史估计速度，Actor 用估计速度、当前帧和命令生成六维动作；训练采样，评估取均值。
2. 按 E-04 裁剪并转成关节目标；后端执行 8 个物理/PD 子步，记录非足端接触历史。
3. 更新基座差分速度、回合步数和步态相位，读取足底反力、参考点速度及净空。
4. `WeightedTask.rewards()` 计算 19 项；`gait_rewards.py` 提供平滑期望接触和四个足端原始代价。
5. `termination()` 判断失败，`apply_failure_cost()` 加终止项；满时长且未失败才算 timeout。
6. 形成下一帧和历史，保存结束前 final observation；课程结算当前命令窗口，再采样存活环境的新命令。
   更新动作/速度历史，只对结束环境 reset，训练返回字典观测及 reward/terminated/truncated。
7. Runner 收集每环境 24 步后执行 PPO 与 Encoder 更新；不是每步立即更新网络。

因此，新足端奖励和课程评分读取同一次转移的物理状态，但使用不同公式与尺度；
回合结束、课程换命令、观测更新不是可以任意交换的步骤。

## 2. 环境与机械、控制规则

### E-01：仿真与本体

- MuJoCo 平地，重力 `(0,0,-9.81)` m/s²，积分器 `implicitfast`；没有地形课程。
- 六关节 PE05 本体资产来自冻结的 PE03 CNC v3；PE05 使用独立任务和算法实现。
- 最大回合时长 20 秒，即 1000 个策略步。
- home 基座高度 `0.2913829166803791 m`；`initial_height=null`、`base_height_target=null`，
  当前高度目标取 home 的 z。训练重置的净空修正不会重新定义奖励高度目标。
- 名义滑动摩擦系数 0.8；物理资产含关节阻尼、armature、碰撞几何等，修改时必须同时审计资产契约。

### E-02：时间尺度

| 层次 | 频率 | 步长 |
| --- | ---: | ---: |
| 物理积分 | 400 Hz | 0.0025 s |
| PE05 PD 电机控制 | 400 Hz | 0.0025 s |
| 策略、奖励、观测更新 | 50 Hz | `Δt=0.02 s` |
| 非足端接触历史采样 | 400 Hz | 每策略步保留 8 个物理样本 |

这是 PE05 的实际合同；不要与 WE11 的 200 Hz 电机控制合同混用。

### E-03：关节顺序和约束

动作、观测、PD、检查点和部署始终使用下表顺序。角度单位 rad，力矩单位 N·m。

| 关节 | home 角度（约） | 物理范围 | Kp | Kd | 力矩上限 |
| --- | ---: | --- | ---: | ---: | ---: |
| `L_hip_` | 0.023160 | [−0.193732, 1.57] | 4.3 | 0.34 | 5.5 |
| `L_thigh_` | −0.312394 | [−1.658, 0] | 4.3 | 0.34 | 5.5 |
| `L_calf_` | −1.254128 | [−1.99, 0] | 4.9 | 0.24 | 14 |
| `R_hip_` | −0.023160 | [−1.57, 0.193732] | 4.3 | 0.34 | 5.5 |

| `R_calf_` | 1.254113 | [0, 1.99] | 4.9 | 0.24 | 14 |

### E-04：动作到执行

1. 网络输出六维无量纲动作，先裁剪到 ±100，再乘 `action_scale=0.25 rad` 得到目标偏移。
2. 再做目标偏移预裁剪：中心为 `q−q_default + mean(Kd)/mean(Kp) × qdot`，
   半宽为 `user_torque_limit / mean(Kp)`，其中 `user_torque_limit=14`。
   **这里使用平均增益，不等价于逐关节精确力矩限幅。**
3. `clip_joint_targets=true`：绝对关节目标裁剪到机械范围，再还原为偏移。
4. 后端按逐关节 PD 执行，并按各关节实际力矩上限限幅；随机化关闭时力矩系数为 1。
5. 环境存储的 `actions` 是最终裁剪后偏移除以 0.25；观测和动作变化奖励使用这个值。
   PPO 的 log-prob 则对应原始高斯采样动作，二者在裁剪发生时不同。

PD 力矩为 `τ_j=clip(s_j[Kp_j(qtarget_delayed,j−q_j)−Kd_j qdot_j],−τmax,j,+τmax,j)`，
其中 `s_j` 为力矩系数，`qtarget_delayed` 为延迟缓冲后的绝对目标。

当前训练延迟为 0 ms；评估延迟为 0 ms。保留在随机化配置里的 25–50 ms 此时不生效。
目标限位裁剪只保证发送的目标在范围内，实际关节状态还受动力学和 MuJoCo 关节限位求解影响。

## 3. 观测与网络规则

### O-01：单帧、历史和命令

环境保持字典观测 `actor / frame / critic / command`，不向策略额外暴露接触计时或课程等级。

| 单帧顺序 | 维数 | 数值含义及缩放 |
| --- | ---: | --- |
| 机身角速度 | 3 | 后端自由关节旋转速度，系数 1 |
| projected gravity | 3 | 世界单位重力方向 `(0,0,−1)` 转到机体系 |
| 相对关节位置 | 6 | `q−q_default`，系数 1 |
| 关节速度 | 6 | 系数 0.1；当前启用物理步位置差分速度 |
| 已施加目标动作 | 6 | 上一个转移实际使用的裁剪后目标动作 |
| 相位 sin / cos | 2 | `sin(2πφ), cos(2πφ)` |
| 步态参数 | 4 | 频率、两脚相位偏移、支撑比、摆脚峰值高度 |
| 合计 | 30 | 单帧裁剪 ±100 |

- `actor`：10 帧，最旧在前，展平 300 维；采样覆盖约 0.2 秒。
- `frame`：当前 30 维，与历史最新帧对齐。
- `critic`：机体系线速度 3 维 + 当前干净单帧 30 维，共 33 维。
- `command`：独立的 `[vx,vy,yaw_rate]` 三维，线速度、角速度缩放均为 1，不在 30 维单帧中。
- 当前观测噪声关闭。Actor 没有直接的机身高度、足底接触、足底净空、真实线速度输入。
- 训练线速度采用基座位置在一个策略步上的差分，再转到当前机体系；不是直接读取瞬时 qvel 平移分量。

### O-02：网络与监督

| 网络 | 输入及维数 | 结构 |
| --- | --- | --- |
| Encoder | 10 帧历史，300 | `300→256→128→3` |
| Actor | 估计速度 3 + 单帧 30 + 命令 3 | `36→512→256→128→6` |
| Critic | 特权观测 33 + 命令 3 + 估计速度 3 | `39→512→256→128→1` |

隐藏层激活 ELU。Encoder 输出用真实机体系三维速度做 MSE 监督。
Actor/Critic 使用 detach 后的估计值；PPO 更新不反传至 Encoder，之后单独更新 Encoder。
策略为对角高斯，初始标准差 1，标准差可学习；训练采样动作，评估和回放使用均值动作。

## 4. 命令与步态规则

### C-01：速度命令

- 命令为机体系平面速度 `[vx,vy]`（m/s）和 yaw rate（rad/s）。
- `heading_command=false`：直接采样 yaw rate，当前不执行目标朝向控制。
- 每次重置采样命令；正常存活时每 10 秒、500 个策略步重采样。
- 每次采样独立以 20% 概率将三维命令全部置零；其余从速度课程网格采样。
  这是采样概率，不保证轨迹时间或日志中恰好 20% 为零。
- `commands/standing_fraction` 判定 `‖cmd_xy‖≤0.1 且 |cmd_yaw|≤0.1`，
  因而也计入一部分小幅非零命令；不能把它当作精确零命令采样率。

### C-02：固定步态与零命令

| 参数 | 当前值 |
| --- | ---: |
| 频率 | 2 Hz，周期 0.5 s |
| 左右相位偏移 | 0.5 |
| 支撑比 | 0.5 |
| 摆脚峰值净空 | 0.03 m |
| 步态重采样周期 | 5 s，但上下界相同，实际参数不变 |

重置全局相位为 0，每步执行后更新 `φ←(φ+Δt×频率) mod 1`。
左脚相位 `φL=φ`，右脚 `φR=(φ+0.5) mod 1`。
相位小于支撑比时为期望支撑，否则为期望摆动。每步推进 0.04 周期，完整周期为 25 个策略步。
奖励在物理执行和相位更新后计算，使用更新后的相位；不是对上一帧相位计分。

**C-03：硬摆动目标 S 与平滑接触目标 d 分开使用。**

- `S_f = 1[φ_f ≥ ρ]`，ρ 为支撑比：用于摆高奖励、摆高误差与摆动期诊断。
- 摆动进度 `u=clip((φ_f−ρ)/(1−ρ),0,1)`，`h_target=H×sin²(πu)`，当前 H=0.03 m。
- 接触奖励使用平滑目标 d，不用 `1−S` 的硬切换。先映射相位：
  支撑段 `x=0.5φ_f/ρ`，摆动段 `x=0.5+0.5(φ_f−ρ)/(1−ρ)`；再计算

`d = Φ(x/κ)[1−Φ((x−0.5)/κ)] + Φ((x−1)/κ)[1−Φ((x−1.5)/κ)]`，

其中 Φ 为标准正态 CDF，奖励 `κ=reward.gait_kappa=0.05`。
支撑中段 d 接近 1，摆动中段 d 接近 0，切换附近平滑过渡。
当前没有有限时长的硬双支撑段；平滑权重重叠不等于新增了双支撑相位。

`reward.zero_command_stance=false`：**零指令也持续交替**，不按命令大小停相位或关闭抬脚目标。
新奖励版本的校验要求此字段为 false，直接改 true 会报错；若要新增零指令站立行为，需要同步改规则与校验。
旧 17 项 weighted checkpoint 缺字段时才保留原零命令双支撑兼容分支。

步态目标是奖励和观测的一部分，不是直接下发的关节轨迹，也不是强制左右脚交替的硬约束。

## 5. 奖励规则

### R-01：总量、时间与归一化

每个策略步：`r = Δt × Σ(w_i × raw_i)`，`Δt=0.02 s`。
失败项在终止判定后加入，同样乘 Δt。回合日志回报为每步奖励直接求和；
PPO 优化的折扣回报使用 `γ=0.99`，二者不能混作同一种回报。
按当前 50 Hz 计算，1 秒后的奖励折扣约 0.605，10 秒后约 0.00657；
因此 20 秒的回合上限不等于所有时刻对当前动作具有相同优化影响。

当前是有符号加权和：无乘积聚合、无总奖励正值截断、无无条件存活奖励。
跟踪项为 `1−归一化平方误差`，可以为负且负向无界；其他多数项为非负代价乘负权重。
当前没有按每项运行均值/方差归一化，也没有总奖励的运行归一化。
部分物理误差按固定尺度无量纲化；PPO 对优势的标准化另见第 10 节。

### R-02：当前完整 19 项奖励

记 `v_b` 为机体系差分线速度，`ω` 为后端 qvel 旋转分量，`g` 为 projected gravity，
`S_f` 与 `d_f` 见 C-03，`F_f` 为足底当前对地反力三维向量。
`v_f` 是**世界系足底固定参考点的刚体速度**，不是 `v_b`，也不是滑动接触点的位置差分。
`L_f=1[h_f<0.05 且 ‖F_f‖≤0.1 且 v_f,z<0]` 为落地掩码。
`a_t` 为 E-04 最终裁剪后的动作；脚相关 Σ 对两脚求和，mean 对两脚平均，关节 Σ 对六关节求和。

| 键 | raw 公式 | 权重 w | 尺度/归约说明 |
| --- | --- | ---: | --- |
| `tracking_lin_vel` | `1−‖v_b,xy−cmd_xy‖²/0.5²` | 1.0 | 两轴误差平方和；std=0.5 m/s |
| `tracking_ang_vel` | `1−(ω_z−cmd_yaw)²/0.5²` | 0.5 | std=0.5 rad/s；不奖励 yaw 角度 |
| `base_height` | `((z−home_z)/0.03)²` | -0.135 | std=3 cm，无容许区 |
| `foot_clearance` | `Σ_f S_f ((h_f−h_target,f)/0.02)²` | -0.1 | std=2 cm，仅硬摆动掩码 |
| `tracking_contacts_shaped_force` | `mean_f (1−d_f)(1−exp(−‖F_f‖²/5))` | -2.0 | 分母 5 N²，摆动脚卸载 |
| `tracking_contacts_shaped_vel` | `mean_f d_f(1−exp(−‖v_f‖²/0.20))` | -2.0 | 分母 0.20 (m/s)²，支撑脚三维速度 |
| `collision` | `Σ_b multiplier_b × I_b` | -5.0 | 七个非足端部件，倍率全部 1 |
| `termination` | `1[terminated]` | -100.0 | 训练结束该回合时额外 -2，timeout 不扣 |
| `feet_regulation` | `Σ_f exp(−max(h_f,0)/0.00025)‖v_f,xy‖²` | -0.08 | 0.25 mm 高度衰减尺度，无接触/相位掩码 |
| `foot_landing_vel` | `Σ_f L_f v_f,z²` | -0.15 | 高度、力、下降速度三条件门控 |
| `orientation` | `(g_x²+g_y²)/0.2²` | -0.3 | 单位重力投影；std 不是角度 |
| `lin_vel_z` | `v_b,z²` | -0.03 | m²/s²，无显式误差尺度 |
| `ang_vel_xy` | `ω_x²+ω_y²` | -0.0015 | rad²/s² |
| `torques` | `Σ_j τ_j²` | -0.00015 | 后端返回力矩，不是整段子步力矩积分 |
| `dof_acc` | `Σ_j ((qdot_j,t−qdot_j,t−1)/Δt)²` | -3.75e-7 | 策略步之间的关节速度差分 |
| `action_rate` | `Σ_j (a_j,t−a_j,t−1)²` | -0.01 | 不除 Δt |
| `action_smooth` | `Σ_j (a_j,t−2a_j,t−1+a_j,t−2)²` | -0.005 | 不除 Δt² |
| `dof_pos_limits` | `Σ_j [max(qsoft_low−q,0)+max(q−qsoft_high,0)]/0.1` | -1.5 | std=0.1 rad，**线性**超限距离 |
| `feet_distance` | `(max(0.08−d_y,0)/0.03)²` | -0.5 | 横向脚距下限 8 cm；std=3 cm |

`contact_schedule` 和 `feet_slip` 不在当前总奖励中。代码先构造兼容分支值，然后在新版本中删除它们，
换成四个新足端项。`reward.slip_velocity_std=0.2` 仍保留供旧版本使用和配置校验，**调它不会改变当前 19 项奖励**。
日志中的 `behavior/slip_speed_mps` 仍然存在，只作接触点滑移诊断，不表示旧滑移奖励仍被相加。

**R-02a：容易混淆的物理定义。**

- 新接触奖励中的 5 和 0.20 是直接使用的指数分母，不是标准差，不再平方；力未按体重归一化。
- `v_f = v_origin + ω_foot × (p_reference−p_origin)`。四个新项中的三个速度相关项使用同一参考点速度。
  PE01 原实现用足端位置策略步差分；当前不是逐字照搬速度测量方式。
- h 是后端按足底几何最低点算出的对平地净空，**后端已裁剪至 `[0,1] m`**。摆高奖励层不再额外截断，
  但也不能读到真实负穿透量。feet_regulation 内的 `max(h,0)` 是防御性处理，正常后端路径已非负。
- feet_regulation 的 0.00025 m 来自 PE01 的 `0.25×0.001`，作为独立常数迁入，**不随 PE05 home 高度变化**。
  净空 1 mm 时其系数已衰减为 `exp(-4)≈0.0183`；它抑制贴地移动，并不要求达到 3 cm。
- 落地阈值 5 cm 高于当前摆高峰值 3 cm，所以无承重且下降时，摆动后半段就可能产生落地速度处罚，
  并非只在即将碰地的最后一瞬间处罚。该项力阈值 ≤0.1 N，与 K-02 的接触诊断 >1 N 不同。
- 软限位以物理范围中点为中心，半宽乘 `soft_joint_limit=0.90`，即每侧保留 5% 行程。
  硬目标裁剪仍使用完整机械范围，不裁剪到软限位内。
- `d_y` 是足底参考点转换到机体系后的横向距离绝对值，不是三维脚距；取绝对值也不能单独识别交叉腿。
- 动作历史在 reset 置零，前两步没有另设“启动步免罚”；一阶/二阶变化按当时历史直接计算。

**R-02b：orientation 的含义。**

`_gravity()` 由 `root` 自由关节所属主机身 `body_link` 的真实四元数，将世界单位重力转到机体系。
不是腿、足部、IMU 安装坐标系或惯性主轴坐标系；观测 IMU 偏置不应用到此奖励。
若机身 z 轴偏离世界竖直方向的夹角为 θ，则 raw=`sin²θ/0.2²`，与 yaw 无关。
倒置也能得到零倾斜代价，因此防摔还依赖第 7 节的终止规则。
当前**没有 5° 死区，也没有 ±1 cm 的高度奖励容许区**；这些历史候选未实施。

### R-03：当前单步贡献核算

以下使用 Δt=0.02 s，仅计算指定分项，不能当作该状态的完整总回报。

| 场景 | 单步/事件奖励 |
| --- | ---: |
| 平面、yaw 跟踪均完美 | +0.02 + 0.01 = +0.03/步 |
| 平面速度误差范数为 0.5 m/s / yaw 误差为 0.5 rad/s | 对应跟踪项各为 0 |
| 主机身倾斜 5° / 10° / 20° | 姿态项约 -0.001139 / -0.004523 / -0.017547 |
| 身体高度误差 1 / 2 / 3 cm | -0.0003 / -0.0012 / -0.0027 |
| 一只摆动脚净空误差 0.5 / 1 / 2 cm | -0.000125 / -0.0005 / -0.002 |
| 完全不抬脚，目标达到 3 cm 峰值 | 摆高项 -0.0045 |
| 完全不抬脚，完整周期平均 | 摆高项 -0.0016875 |
| 摆动中段 d≈0，一只脚承受足够大载荷；另一脚期望支撑 | 接触力项接近 -0.02 |
| 支撑中段 d≈1，一只脚速率 0.2 m/s；另一脚不计速度代价 | 支撑速度项约 -0.003625 |
| 一只脚净空为 0，水平速度 0.2 m/s | 近地移动项 -0.000064 |
| 一只脚满足落地掩码，向下速度 0.2 m/s | 落地速度项 -0.00012 |
| 任一非足端部件在本策略步发生碰撞 | -0.1；大腿、小腿、机身相同 |
| 一个关节超出软限位 0.1 rad | 软限位项 -0.03 |
| 脚距 5 cm，比下限不足 3 cm | 脚距项 -0.01 |
| 训练真实失败 | 该回合终止步额外 -2 |

在零命令、姿态/高度理想、双脚持续承重的简化情形，忽略其他代价：
`平均 r≈0.03−0.02−0.0016875=0.0083125/步`。
这是静态支撑的预算示例，不证明它比所有可行步态都差；实际动作、力矩、碰撞与存活时长还需一起比较。
两个接触代价均有饱和区，高载荷时继续增加力几乎不改变分数；连续公式不意味着全范围都有同样强的改善信号。

### R-04：权重与误差尺度如何影响处罚

- 对 `w(e/s)²`，固定物理误差时有效系数为 `w/s²`。权重绝对值翻倍，处罚翻倍；std 减半，处罚变四倍。
- `dof_pos_limits` 是线性归一化，有效系数为 `w/s`，不能按平方规则换算。
- 净空目标 H、误差尺度 s、权重 w 分别控制目标轨迹、敏感度、扣分预算，不是同一个参数。
- 减小 `gait_force_sigma` / `gait_vel_sigma` 会让较小的力/速度就进入饱和区；增大它们会放宽误差，权重控制最大预算。
- `gait_kappa` 改变相位切换的过渡宽度，不直接改变周期或支撑比。
- 当前平面跟踪只设一个权重和一个 std，vx/vy 共同用平方和；单独给 vx/vy 容差需要改公式和配置合同。
- 总奖励按 dt 缩放，失败项也是如此；动作差分没有除 dt，改变策略频率后不能假定尺度自动等价。

这些是当前公式的敏感度说明，不是在本次文档更新中建议或实施新权重。

## 6. 接触与碰撞规则

### K-01：非足端碰撞

惩罚部件：`body_link`、`L_hip_Link`、`L_thigh_Link`、`L_calf_Link`、
`R_hip_Link`、`R_thigh_Link`、`R_calf_link`。**所有部件倍率均为 1**。
两个足部不在碰撞惩罚列表中。

每个物理样本分别判断：

- 地面接触：该部件地面净接触力的模长 **>1 N**。
- 其他接触：总净接触力减地面净接触力，所得向量模长 **>1 N**；日志命名为 `self_fraction`。
- 部件 `I_b=1`：本策略步 8 个样本中，任一样本满足地面或其他接触。

同一部件同时发生两类接触只计一次；同一部件在 8 个样本中碰一次和碰满 8 次，
该步碰撞奖励相同。不同部件相加；一次自碰撞可能涉及多个被计分部件。
这是**净合力阈值**，不是逐接触点几何碰撞计数；方向相反的接触力可能抵消。

### K-02：足底接触

sole geom 为 `L_foot_Link_collision_sole_0` 和 `R_foot_Link_collision_sole_0`，对地反力来自这些指定几何。
需要区分三种使用方式：

| 用途 | 规则 |
| --- | --- |
| 新摆动期接触力奖励 | 使用当前 `‖F_f‖²`，无 1 N 布尔阈值，按平滑目标 d 加权 |
| 新落地速度奖励 | `‖F_f‖≤0.1 N` 且 h<5 cm、v_z<0 |
| 足底接触诊断 A、占空比、离地计数、旧滑移诊断 | 当前竖直反力 `F_f,z>1 N` |

上述足端项使用当前足端状态，没有采用非足端碰撞“8 个物理样本取任意触发”的历史聚合。
足底固定参考点速度用于新奖励；力加权接触点的刚体速度用于课程评分及滑移诊断。
无接触时后者回退为参考点速度。它们在足端旋转时可以不同，调参时应看对应的物理量。

## 7. 终止与截断规则

### T-01：真实失败 `terminated`

满足任一条件即失败：

1. 任一 K-01 部件连续触地达到 **0.1 s = 40 个物理样本**。
   各部件独立计数，按时间正序处理本策略步历史，离地清零，可跨策略步累计。
   本步中途达到阈值、末尾离地，仍判失败。自碰撞不累计地面计时。
2. `z<0.15 m` 或机身倾角 `>60°` 的组合条件连续成立 **0.1 s = 5 个策略步**。
   倾角为 `acos(−g_z)`。两种异常共用一个连续计数器；二者交替发生也可能累计到阈值。

碰撞惩罚和终止惩罚可以在同一步同时发生。
`env.failure_gravity_z`、`failure_contact_force`、`termination_bodies` 等旧字段仍存在，
但 weighted_v2 的失败条件由上述逻辑决定，不能只修改旧字段就认为已改变当前终止规则。

### T-02：时间截断 `truncated`

`episode_steps≥1000` 且没有真实失败时，按 20 秒 timeout 截断。
失败和 timeout 同步发生时失败优先。训练自动重置结束的环境。
真实失败不 bootstrap；timeout 使用重置前 final observation 的价值 bootstrap；
GAE 递推在两种结束处都停止，不穿过 reset。

## 8. 重置规则

### S-01：训练 reset

1. 从 home 姿态开始，在重置时应用该环境的随机化等级。
2. 当前动力学随机化关闭，因此 level=0，关节扰动实际为零；基座初速度和关节初速度为零。
   YAML 保留的关节 ±0.1 rad 仅在相应随机化等级生效时才产生扰动。
3. 将关节采样范围约束在物理限位内，通过缓存足底几何调整基座 z，使最小足底净空为 1 mm。
4. 最多 8 次普通尝试；仍有异常接触则额外回退到 home 关节姿态并重新对齐净空。
   检查净接触力模长是否大于 `1e−6`；回退仍异常时抛错。
5. 清零本环境的接触计时、失败计时、回报、动作历史、速度历史、相位、后端延迟缓冲等状态。
6. 采样新命令和步态，将初始观测复制填满 10 帧历史；不是用全零历史起步。

仅重置结束的环境；其他环境状态继续保留。速度课程的共享网格权重不因单环境 reset 清零。

### S-02：训练评估与交互回放的差异

- 训练内置评估开启 `evaluation_reset_noise` 路径，但当前关节/速度噪声幅度均为 0，仍执行净空对齐。
- 交互回放未开启该路径，直接使用精确 home，不做训练式净空修正。
- 回放不自动重置，摔倒后仍继续运行；不能以“窗口还在运行”判断训练终止没有生效。
  底层失败条件持续成立时仍会逐步产生 termination 代价；“失败一次扣 -2”描述的是训练结束并 reset
  或评估停止计分的回合语义，不是对无限继续的交互回放做永久锁存。
- 当前相位、初态、动力学都固定且评估动作取均值，多并行评估可能产生重复轨迹；
  8 个评估环境不等同于覆盖了 8 种独立扰动场景。

### U-03：四项晋级分数（不加入 PPO 奖励）

| 分数 | 每步公式 | 窗口阈值 |
| --- | --- | ---: |
| 平面跟踪 | `exp(−‖cmd_xy−v_xy‖²/0.25)` | ≥0.8 |
| yaw 跟踪 | `exp(−(cmd_yaw−ω_z)²/0.25)` | ≥0.7 |
| 摆动期力 | `1−mean_f[(1−Dsoft_f)(1−exp(−‖F_f‖²/(0.08Mg)²))]` | ≥0.9 |
| 支撑期速度 | `1−mean_f[Dsoft_f(1−exp(−‖v_contact,f‖²/10))]` | ≥0.9 |

`F_f` 是足底当前地面反力三维向量，速度也用三维范数；`Mg` 为本环境机器人重力大小。
分母 `0.25` 和 `10` 是直接使用的数值，不再平方。
`Dsoft` 也用平滑相位生成，但其参数独立于奖励：
先把支撑段相位映射到 `[0,0.5)`、摆动段到 `[0.5,1)` 得到 x，再计算
`Φ(x/κ)[1−Φ((x−0.5)/κ)] + Φ((x−1)/κ)[1−Φ((x−1.5)/κ)]`，
其中 Φ 为标准正态 CDF，`κ=0.07`。

当前课程仍保留 PE03 风格评分，**没有随足端奖励迁移而同步改为 PE01 参数**：

| 差异 | PPO 足端奖励 | 速度课程评分 |
| --- | --- | --- |
| 平滑 κ | 0.05 | 0.07 |
| 力的指数分母 | 5 N² | `(0.08Mg)²` |
| 速度的指数分母 | 0.20 (m/s)² | 10 (m/s)² |
| 足端速度 | 固定参考点速度 | 力加权接触点速度 |
| 使用位置 | 每步加入总奖励 | 500 步窗口晋级判据 |

课程成绩需要四项同时达标。即使跟踪奖励改善，接触力分数不过关仍无法扩展命令。

## 10. PPO 与优化规则

| 参数 | 当前值 |
| --- | ---: |
| 折扣 γ / GAE λ | 0.99 / 0.95 |
| 每轮 PPO epoch / minibatch | 5 / 4，共 20 次更新 |
| 每轮 Encoder epoch / minibatch | 5 / 4，共 20 次更新 |
| PPO / Encoder 初始学习率 | 0.001 / 0.001 |
| PPO clip ratio | 0.2 |
| Value loss 系数 / clipped value loss | 1 / 开启 |
| Entropy 系数 | 0.01 |
| PPO 最大梯度范数 | 1 |
| desired KL / schedule | 0.01 / adaptive |

优势在整轮展平样本上做 `(A−mean(A))/(std(A)+1e−8)`。
PPO 的 Adam 学习率按 KL 乘/除 1.5，范围 `[1e−5,1e−2]`；Encoder 使用独立 Adam，
不随该自适应学习率变化。总奖励和价值目标没有另做运行均值/方差归一化。
优势标准化不能消除各奖励项相对尺度不合理的问题。

## 11. 评估与日志解释

### V-01：正式默认评估与短训验收不是同一套参数

| 设置 | 当前正式 `pe05_gait_fixed` | 100 轮 `pe01_gait` 短训 / 独立校准评估工具 |
| --- | --- | --- |
| 训练内评估间隔 | 每 100 轮 | 短训每 25 轮；独立工具按指定 checkpoint 执行 |
| 每类命令环境数 / 最长回合 | 8 / 20 s | 8 / 20 s |
| 零命令 | [0,0,0] | 相同 |
| 前后命令 | vx=±0.3 m/s | 相同 |
| 横向命令 | **vy=±0.15 m/s** | **vy=±0.1 m/s** |
| 转向命令 | yaw=±0.4 rad/s | 相同 |
| 回合平均高度误差门槛 | **≤0.01 m** | **≤0.02 m** |
| 平面 / yaw 平均误差门槛 | ≤0.15 m/s / ≤0.2 rad/s | 相同 |
| 非足端接触比例门槛 | ≤1% | 相同 |

正式值来自任务 YAML 的 `evaluation.*`；`gait_fixed` 实验只改变工作流命名，不改变上述门槛。
短训覆盖来自 `conf/pe05/experiment/pe01_gait.yaml`；独立工具
`tools/evaluate_pe05_calibration.py` 也显式采用右列命令与 2 cm 高度门槛。
所以直接调用独立工具的报告与正式训练中的 `Eval/*` 不能不加说明地混为同一验收。

评估使用均值动作，关闭随机化及课程更新。每回合成功要求：无真实失败、完整达到 1000 步，
并且该回合四项平均质量同时达标。每类命令统计 `success_rate` 和 `failure_rate`，不是在训练中新增终止条件。
独立工具的组级 acceptance 另检查失败率≤5%、平均时长≥19 s 以及组均值门槛；它并不直接要求
`success_rate≥95%`。8 个样本时出现一次失败就达到 12.5%，已经超出 5%。

各组连续指标按有效存活步统计，终止步计入，死亡后的状态不计入；跨命令组汇总等权。
`standing` 只是零命令组名，仍按 C-02/C-03 交替目标计算。
`standing_fraction` 统计高度误差<3 cm、倾角<10°、平面速度<0.1 m/s 且无非足端接触的步比例，
不是双脚支撑占比，也不是成功率。

**V-01a：步态诊断如何读。**

| 指标（每组、左右脚分别统计） | 计算口径 |
| --- | --- |
| `gait/{side}/swing_loaded_fraction` | 硬摆动 S 为真时，竖直足力>1 N 的比例 |
| `gait/{side}/stance_speed_mps` | 硬支撑 S 为假时，固定参考点三维速率均值 |
| `gait/{side}/contact_duty_fraction` | 所有有效步中足底接触 A 为真的比例 |
| `gait/double_support_fraction` | 两只脚 A 同时为真的比例 |
| `gait/{side}/liftoffs_per_second` | A 从真到假的次数 / 有效仿真秒数；首样本不计跨越 |
| `gait/{side}/clearance_error_p50_m`、`p90_m`、`p95_m` | 硬摆动步中 `abs(h−target)` 分位数 |
| `gait/{side}/mid_swing_drag_fraction` | S 为真且目标>2 cm 时，实际净空<5 mm 的比例 |
| `gait/{side}/reward/*` | 四个足端项及摆高项分配到该脚的实际贡献，已含权重/dt及接触项的两足平均因子 |
| `reward/*` | 该评估组的全机器人 19 项贡献，含动作平滑和失败处罚 |

2 Hz 理想规律步态通常每脚每秒离地两次，但原始接触阈值跨越可能含抖动，不能单看次数判定交替。
没有摆动或中段样本时相关结果以 0 占位，同时记录 `swing_samples` / `mid_swing_samples`；无样本不代表合格。
这些步态诊断**尚未加入综合 success/acceptance 的硬门槛**，必须同时检查曲线和回放，不能只看“评估通过”。

### V-02：TensorBoard 与 JSONL

| 分组 | 含义 |
| --- | --- |
| `Train/*` | 回合回报、回合秒数/步数、样本数、轮数；回合指标为最近最多 100 个完成回合的均值 |
| `Loss/*`、`Policy/*`、`Perf/*` | 优化损失、策略标准差、采样/更新性能 |
| `reward/*` | 乘权重与 Δt 后的分项贡献；先环境平均，再对本轮 24 步平均 |
| `raw_reward/*` | 对应未乘权重和 Δt 的值，采用同样聚合 |
| `contact/*/ground_fraction`、`self_fraction` | 每策略步内是否发生该部件接触的比例，不是物理接触持续时间比例 |
| `contact/*/continuous_ground_seconds` | 每步先取并行环境中该部件持续触地时长最大值，再对 rollout 求均值 |
| `behavior/*` | 高度、跟踪、摆脚、滑移的物理量误差 |
| `failure/*` | 各步失败条件的诊断比例，不等于完整回合失败率 |
| `command_curriculum/*` | 速度网格范围、活跃单元比例、窗口计数与四项分数 |
| `curriculum/*` | 动力学随机化等级 |
| `Eval/*` | 固定命令评估；JSONL 对应 `evaluation/*`，包括 V-01a 的分脚步态诊断 |

课程累计窗口计数也经过 rollout 均值，因此显示小数时不表示出现“半个窗口”。
`behavior/slip_speed_mps` 包含未接触脚的零值；`clearance_error_m` 仅对期望摆动脚统计。
碰撞均值小可能来自发生率低，不能据此直接决定增大权重。
接触占比低也可能同时存在很高的回合失败率，应同时看失败率、存活时长和分部件接触。

## 12. 训练、回放、保存与兼容

```bash
cd /ssd/Aar_Unilab

# 只查看启动预设
bash tools/train.sh pe05_gait_fixed --dry-run

# 默认训练；本次预算可显式覆盖，例如 algo.max_iterations=500
bash tools/train.sh pe05_gait_fixed

# 手柄回放最新模型；checkpoint 默认 -1
bash tools/train.sh pe05_gait_fixed mode=play

# 固定命令回放
bash tools/train.sh pe05_gait_fixed mode=play play.command_source=fixed 'play.command=[0.2,0,0]'

# TensorBoard；已有服务时打开 http://127.0.0.1:6006 即可
/ssd/conda/envs/aar_unilab/bin/python -m tensorboard.main \
  --logdir logs/pe05_gait_fixed/tensorboard_runs --host 127.0.0.1 --port 6006
```

`pe05` 是正式 profile 的兼容别名；`pe05_smoke` 是独立工程测试入口，日志根目录为
`logs/pe05_gait_fixed_smoke`。新正式 TensorBoard 名称为
`PE05__pe05_flat-mujoco__gait_fixed__<训练开始时间>`，历史 run 保留原身份。

`checkpoint=-1` **先按训练目录名中的时间选最新 run，再按数值轮次选 checkpoint**，不用文件修改时间。
最新 run 尚无模型时明确报错，不回退到旧 run；也可显式传 `.pt` 路径。启动时打印最终路径。
回放默认手柄、运行至窗口关闭、不暂停、不额外弹曲线；`play.paused=true` / `play.plot=true` 可调整。
正式 profile 遥测目录为 `logs/play/pe05/pe05_flat/fixed`。
回放步态和延迟默认取 checkpoint 保存值，只有显式 `play.gait=` / `play.delay_ms=` 才覆盖。

检查点保存网络、两套优化器、随机数状态、环境状态、课程网格与窗口、近期回合统计及完整配置。
`training.export=true` 时结束训练会生成 release；**导出成功不是策略效果验收通过**。
续训使用 `training.resume=<路径>`；`algo.max_iterations` 是本次追加轮数，而非累计截止轮次。

训练合同排除 `mode/checkpoint/play/training`、`algo.max_iterations` 和 `algo.save_interval`，
但保留任务、控制、网络和其余算法配置，并检查资产指纹和观测布局。
奖励、重置、终止、命令课程或网络合同改变后应开启新 run；调整保存/评估频率及日志位置不等于换奖励合同。
由于整个 `training` 块被排除，校验并不自动保证其中任意变更都不影响训练过程，续训时仍需检查实际配置。

| 保存的奖励版本 | 加载行为 |
| --- | --- |
| `weighted_v2` 且缺少 `gait_reward_version` | 按该 checkpoint 保存的旧 17 项奖励计算 |
| `weighted_v2` 且 `gait_reward_version=pe01_shaped_v1` | 当前 19 项奖励；要求零命令交替 |
| 未知奖励版本或奖励键集合不符 | 拒绝加载/启动 |

新旧合同之间不能直接续训。修改当前 YAML 不会改写历史模型的奖励和控制行为，回放也不是继续优化策略。
正式目录、兼容链接和旧产物归档映射见 [PE05 操作指南](PE05_WORKFLOW.md)，历史模型指纹未改变。
