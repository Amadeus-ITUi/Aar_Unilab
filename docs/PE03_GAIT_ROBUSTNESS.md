# PE03 步态训练随机化

配置所有者是 `conf/pe03/task/pe03_gait_flat.yaml`，固定和可调步态实验共用。
本次新训练从头开始。`domain_rand.curriculum` 控制整体随机化课程；
`noise.level=1.0` 是观测噪声的目标倍率，实际噪声还乘本回合随机化等级。
奖励、终止、网络、命令课程以及 400 Hz 物理/PD、50 Hz 策略频率保持原值。

```bash
env -u PYTHONPATH PYTHONNOUSERSITE=1 \
  /ssd/conda/envs/aar_unilab/bin/python scripts/train_pe03.py \
  +experiment=gait_fixed algo.max_iterations=500 \
  training.resume=null training.stage_from=null
```

默认 4096 环境、24 步/轮、每 100 轮评估 64 个最长 20 秒的回合。
日志仍进入 `logs/pe03_gait_fixed/` 下的新时间目录，旧日志不覆盖。

## 参数与采样周期

下表为 level=1 的目标范围。每个仿真环境初始化时采样一次目标参数，并缓存
名义参数；升级时统一重置所有环境，并插值到新等级。普通重置不重复采样
物理参数；checkpoint 保存采样端点、实际参数和各环境本回合的等级。

| 参数 | 范围 |
|---|---|
| 滑动摩擦 | 0.1～2.0，64 个随机桶，机器人和地面使用同一个值 |
| 机身附加质量 | ±0.2 kg |
| 机身局部质心 xyz | 各 ±1 cm |
| 刚体惯量倍率 | 0.8～1.2；非根刚体质量同步使用各自倍率 |
| Kp / Kd / 力矩倍率 | 各关节分别独立采样 0.8～1.2 |
| PD 默认目标偏移 | 各关节 ±0.02 rad，最终目标仍受硬限位约束 |
| 动作延迟 | 固定 20 ms，即 8 个物理步、1 个策略步 |
| IMU roll / pitch 偏差 | 各 ±1.2°，采用 PE01 的偏差旋转方式 |

摩擦的扭转和滚动分量不变；不增加未经标定的恢复系数映射。力矩倍率后仍执行
原有力矩限幅。接触力奖励和 Critic 使用每个环境实际总质量计算的 mg 归一化。

## 随机化等级课程

```yaml
domain_rand:
  curriculum:
    enabled: true
    initial_level: 0.0
    increment: 0.1
    max_level: 1.0
    strategy: per_env_mean
    mean_episode_length: 950
```

固定、可调步态预设共用这套规则。每轮统计中，每个并行环境在当前等级
**各贡献第一个自然结束的回合**，包括提前失败；同一环境随后结束的回合不重复
计入，也不覆盖先前失败。所有环境各贡献一次后，计算这些回合的平均长度。
均值达到 950 个策略步（19 秒）即增加 0.1，只增不减、最高为 1。
未达标则保持等级、清空本轮记录，重新收集各环境的一次结果。

统计容量随 `algo.num_envs` 自动确定，没有额外的 4096 回合门槛，也不使用最近
100 回合或 50% 达标比例。例如 50 个回合为 1000 步、另 50 个为 500 步，
均值仅 750 步，不会升级。三回合 1000 步和一回合 800 步的均值恰为 950，
可以升级。当前轮未收齐时的均值只作诊断，不能触发升级。

升级发生在当前策略步奖励结算之后：真实失败仍为 `terminated`，自然超时仍为
`truncated`；其余正在运行的旧等级回合统一标记为升级 `truncated`。保留旧参数、
旧命令对应的末帧观测供 PPO bootstrap，GAE 不跨回合传播。随后全部环境同步
应用新等级、重置姿态、历史、动作、延迟 FIFO 和推力计时，再清空课程记录。
升级截断不计入课程成绩，也不计入普通回合长度/回报；单独累计截断次数。
截断时尚未结束的命令统计窗口直接丢弃，不作为速度/步态课程的成功或失败。

控制台及 `Train/mean_episode_length` 仍是最近 100 个自然结束回合的平均值，
可能混有旧等级，只作训练日志。升级只使用上述当前等级、各环境等权的统计。

参数使用 `nominal + level × (target - nominal)` 插值：Kp/Kd/力矩及惯量倍率
从 1 扩展，摩擦从每个 geom 的名义值扩展，质量/重心/IMU/零点偏差从零扩展。
关节重置角度、观测噪声和推力幅度乘本回合 level。level=0 时无上述扰动；
最低足底仍对齐 1 mm。**延迟始终为 20 ms，初始线速度和角速度始终为零**。

物理参数插值仅在升级时的统一重置执行；普通重置复用本等级参数。不在每策略步
解析模型或增加足底几何计算。统计只处理自然结束的环境索引，使用缓存数组记录
本轮结果；统一重置仅在升级时发生，不额外增加持续运行的仿真步数。

level=1 时逐策略时刻采样独立均匀观测噪声：角速度 ±0.2 rad/s、投影重力各分量 ±0.2、
关节位置 ±0.08 rad、关节速度 ±1.5 rad/s（归一化后 ±0.15）。同一时刻所有
观测读取复用同一份噪声，命令替换不重新抽样。动作、命令、步态和相位不加噪声；
奖励、Critic 额外状态和速度估计标签使用真值。

每回合每 5 秒在一个物理步内施加机身外力，采用 PE01 方向采样和世界竖直分量
减半的规则。各环境使用自己的随机化机身质量，`max_push_vel=0.5` 是冲量尺度，
不代表直接赋值速度。回合重置后重新计时。

## 重置与计算开销

各关节在 home ±(0.1 × level) rad 与硬限位的交集内均匀采样；机体线速度、角速度及
关节速度均从零开始，不随机初速度。姿态采样中心始终为
名义 home，独立于 PD 零点偏移。基座 xy、朝向保持 home，奖励高度目标不移动。

`ResetSoleGeometry` 初始化时缓存腿部运动链和碰撞足底顶点；每次仅对重置子集
批量计算世界 z 方向投影，使用带符号高度把最低足底放到地面上方 1 mm。
每侧 230 个顶点；不在运行时读模型、解析网格、求 IK 或逐环境调用 mj_forward。
法向投影临时数组按 512 环境分块。正常情况只执行一次后端 reset。

利用正常 reset 已产生的初始接触反力筛查异常接触，有异常的环境最多重采样
8 次，然后回退到对齐足底后的 home。该筛查复用传感结果，没有额外全量碰撞
扫描；零反力不能作为不存在几何交叠的严格证明，几何穿透另以离线样本检查。
相位回到 0.05，动作、延迟 FIFO、失败/接触计时清零，初始带噪帧填满 30 帧历史。

动作历史记录限幅后**发入** FIFO 的归一化命令，实际 PD 使用延迟输出。
完整历史、当前帧和命令的部署接口与网络维度保持不变。

## 评估、回放和恢复

`training.evaluation_conditions=randomized`：定期评估冻结在训练当前目标等级，
使用固定随机种子和 Actor 均值动作；评估回合不会推进课程。独立调用评估器
而未传入等级时使用最高等级。报告与 TensorBoard 记录评估等级；低于最高等级
不能通过阶段验收。保留全部命令范围、原验收阈值和
连续三次通过要求。评估 JSON 记录协议指纹及摩擦、质量、延迟采样，阶段切换
必须匹配协议；旧无扰动验收不能解锁新阶段。

普通 play 使用名义参数、home、零初速度，不主动注入随机噪声或推力；支持
`play.delay_ms=25` 等固定延迟。ONNX 内不加入仿真噪声，导出配置保留归一化、
历史规则和选定的回放延迟，Python/C++ 使用相同命令历史与 FIFO 规则。

严格 resume 要求相同环境合同，保存并恢复随机数状态、物理参数、噪声缓存、
历史、推力计时和延迟队列，还包括等级、各环境本轮结果及未完成标记、判定次数、
升级截断计数、采样端点和每个环境当前等级。旧 checkpoint 缺少课程配置时保留
原来的固定强度行为；保存旧窗口均值或最近回合达标比例规则的 checkpoint
恢复时仍使用旧规则，包括原来的分环境重置切换。不能通过严格
resume 改变课程判定合同，新预设训练使用
`training.resume=null training.stage_from=null`。

TensorBoard 增加 `randomization/*` 和 `reset/*` 日志，包括摩擦、质量、延迟、
增益和力矩倍率的均值/范围、推力发生比例
及冲量、重置高度修正、尝试次数和回退比例。`Eval/randomized_conditions` 标记
评估条件，详细配置及指纹在对应 `evaluation_N.json`。

课程曲线在 TensorBoard 中查看：

- `randomization/level`：目标等级；`randomization/applied_level_min/mean/max`：
  各环境实际等级，新规则下升级后同步一致。
- `randomization/episode_count`、`required_envs`：本轮已贡献结果的环境数和所需
  环境总数；`round_coverage` 为收集覆盖率。每轮完成判定后计数清零。
- `randomization/mean_episode_length`：本轮已收集结果的均值，单位策略步；
  收集未完成时只作诊断。`episode_length_threshold` 为升级阈值 950。
- `randomization/last_check_mean_episode_length`、`last_check_level`：最近一次
  收齐全部环境后的判定均值及等级；用这两个值核对升级原因。
- `randomization/checks`、`promotions`：累计判定次数及升级次数。
- `randomization/promotion_truncations`：累计被升级主动截断的回合数；不包括
  同一步真实失败或自然超时的回合，也不参与升级均值。
- `randomization/noise_level`：实际生效的平均噪声倍率。
- `Eval/randomization_level`：此次评估等级。

等级与计数记录每轮末状态，避免在升级轮对 level 做均值而显示虚构等级。

## 验证方法

专项测试：`tests/pe03/test_pe03_gait_robustness.py`；包含低摩擦的实际 MuJoCo
接触系数、几何对照、稀疏重置、带噪帧一致性、真值监督、物理步延迟、单步推力、
跨重置的精确恢复，以及 Python/native PD 对照。

`tools/benchmark_pe03_reset.py` 对照精确实时计算与预先缓存的**相同修正值**，
验证两者轨迹完全一致后统计吞吐；包括正常回合和每 0.1 秒全批重置的压力场景。
这单独衡量高度算法的额外开销，不把不同初始物理状态引起的耗时差混入结果。
工程验证和策略步态验收分别记录；短训成功不代表新策略已学会稳定步行。

`logs/pe03-validation/robustness_20260920/`）：
