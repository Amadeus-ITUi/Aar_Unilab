# WE11 日常启动状态机

`start_robot.sh` 现在只负责加载已构建工作区并启动唯一的 supervisor。启动路径
不再运行编译、`sudo` 或终端交互；人工确认全部来自手柄。

更新后的下位机已将 P3/P6 速度能力提升至 `±50 rad/s`，覆盖训练合同的
`±35 rad/s`。新指纹只读、STANDBY、零策略和 3 秒真实 MNN POLICY 均已完成台架
验收；2026-09-10 下地回归发现的 bridge 整帧越界拒绝已经改为逐关节裁剪并通过自动
测试。完成下地短时复测前，日常入口仍只放行到 Standby。

## 日常状态与灯光

```text
橙色呼吸  树莓派已开机，手柄未连接或不可读
绿色呼吸  手柄已连接，可按上+X 启动程序
白色呼吸  上+X 已接受，启动器与 supervisor 正在无黑屏交接 RGB
白色呼吸  开机、建立 ROS 图
蓝色呼吸  ESD-Link 会话/schema/指纹及原生 P1~P8/IMU 检查
青色呼吸  等待普通启动；P1~P8 整体失能，X 切换模式，Y 执行
绿色呼吸  已选择倒地自启；P1~P8 整体失能，X 切回，Y 执行
白色闪烁  P1~P6 用 3 秒斜坡进入目标姿态，P7/P8 保持入场位置
绿色闪烁  倒地自启只整体使能；不发保持/默认姿态帧，等待首帧真实策略
白色常亮  Standby
绿色常亮  Policy
```

## 按键

- `Y`：等待状态下执行当前所选启动模式；Standby 或 Policy 中请求
  冻结下位机对 P1～P8 整体 `SAFE_DAMPING → DISABLED`。
- `X`：等待状态下切换“普通 Standby 启动/倒地自启 Policy”，青色/绿色呼吸
  分别表示当前选择；Standby/Policy 中仍为一键切换。进入 Policy 前执行机器门控，拒绝时
  保持 Standby。
- 方向键上 + `A` 持续约 0.25 秒：在正常或故障状态安全退出全部进程并失能电机。
- 程序停止后，方向键上 + `X` 持续约 0.25 秒并松开：重新执行完整启动和自检。
- `LB+RB` 维护标定入口本轮未接入；现有独立零点脚本仍可单独使用。

## 自动判定

- bridge 必须建立 schema 1 有效会话，配置指纹匹配，P1～P8 与 IMU 有效，数值有限，
  且下位机无 fault/offline。
- 状态频率、帧间隔和 ROS 话题年龄仅用于诊断和验收，不作为 supervisor 运行期
  二次超时门限。无新状态则推理不发新命令，由下位机 200 ms 看门狗退出。
- 推理节点启动后只需观察到一条有限的六维零动作，不再另行统计 ROS 输出频率。
- 从 STANDBY 进入 POLICY 时先开启推理输出，再交接 bridge 控制权；退回 STANDBY
  先恢复 bridge 保持，再停止策略，避免在 200 ms 下位机看门狗前留出无命令窗口。
- 倒地自启从 DISABLED 直接请求 ACTIVE：bridge 只发整体使能，使下位机停在
  `ENABLED_WAIT_COMMAND`，不插入保持或默认姿态命令；supervisor 随后开启推理，首条
  执行器命令直接使用真实 Policy 输出。

## 超时预算与故障区分

- STANDBY 的 3 秒姿态斜坡由 bridge 生成完整 P1～P8 命令；supervisor 最多等待 15 秒的
  服务结果。这是用户请求/状态转换期限，不是通信快路径的周期超时。
- `*_SERVICE_UNAVAILABLE` 表示 ROS 服务在发现期限内不存在；
  `*_RESPONSE_TIMEOUT` 或 `STANDBY_TRANSITION_TIMEOUT` 表示服务已经发出请求，
  但节点没有在动作期限内返回；`*_REJECTED` 表示服务正常返回并明确拒绝。
- 机翼 RC 兼容服务和推理模式切换的响应期限为 5 秒。
- 正常 `Y` 软失能服务等待下位机完成 SAFE_DAMPING，supervisor 使用 8 秒响应期限。服务失败
  会改用立即硬失能并进入故障锁存；掉线、急停和进程退出不执行渐变。

## 故障显示

故障灯永久重复“红色 1 秒 → 分类色 1 秒 → 白色短闪子编号 → 熄灭 2 秒”。
分类色为：蓝=CAN/电机，紫=IMU，青=手柄/模型/设备，黄=翼，品红=ROS/推理，
橙=维护。日志同时记录稳定故障码和完整原因。故障锁存后不会自动重启；记下灯码后
长按方向键上 + `A` 退出，修复硬件，再长按方向键上 + `X` 并松开即可重新自检。

RGB 初始化或运行时失效按安全关键故障处理：不得继续使能电机。

## 开机自启

模板位于 `config/system/we11-deploy.service`。维护终端先执行一次
`./start_robot.sh --build`，再执行 `./config/system/install-we11-host.sh --enable`。
安装脚本只启用下次开机的手柄生命周期启动器，不会当场启动机器人。服务自动加载
`xpad` 并持续等待手柄；未连接时橙色呼吸，连接可用时绿色呼吸。长按方向键上 + `X` 并松开才会无参数运行
`start_robot.sh`。按键被接受后立即改为白色呼吸，并保持到 supervisor 完成 RGB
接管；正常启动时不再出现交接灭灯。即使 CAN/IMU 未接好，启动器仍可工作并让 supervisor 显示对应
故障码。机器人子程序不会自动重启，`WE11_AUTOSTART=1` 仍拒绝任何 `--build`。
