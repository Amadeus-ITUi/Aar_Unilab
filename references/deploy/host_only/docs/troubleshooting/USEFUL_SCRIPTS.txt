ROS 2 deploy_tools package
--------------------------
Canonical implementations live under src/deploy_tools/scripts:

  can/          SocketCAN inspection and maintenance tools
  diagnostics/  ROS diagnostics and runtime recorders
  control/      Explicit runtime parameter tools
  analysis/     Offline CSV plotting and comparison

After a build and source, tools can be called with:

  ros2 run deploy_tools <tool_name> [arguments]

Examples:

  ros2 run deploy_tools read_motor_status --help
  ros2 run deploy_tools read_all_motor_status --help
  ros2 run deploy_tools check_imu_data --help
  ros2 run deploy_tools set_foot_pd --help

Installing deploy_tools starts no nodes. Running a tool retains its original
behavior; some CAN tools can transmit frames when requested by their arguments.
