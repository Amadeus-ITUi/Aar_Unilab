# WE11 日常启动状态机

`start_robot.sh` 现在只负责加载已构建工作区并启动唯一的 supervisor。启动路径
不再运行编译、`sudo` 或终端交互；人工确认全部来自手柄。

## 日常状态与灯光

```text
橙色呼吸  树莓派已开机，手柄未连接或不可读
绿色呼吸  手柄已连接，可按上+X 启动程序
白色呼吸  上+X 已接受，启动器与 supervisor 正在无黑屏交接 RGB
白色呼吸  开机、建立 ROS 图
蓝色呼吸  CAN 与 1~8 号电机反馈自检
紫色呼吸  IMU 一个 1 秒窗口自检
青色呼吸  手柄和下肢反馈自检
黄色闪烁  7/8 号翼自动执行镜像物理 90° 启动目标
青色呼吸  等待普通启动；1~6 号失能，右摇杆可控机翼，X 切换模式，Y 执行
绿色呼吸  已选择倒地自启；1~6 号失能，右摇杆可控机翼，X 切回，Y 执行
白色闪烁  1~6 号电机用 3 秒斜坡进入目标姿态
绿色闪烁  倒地自启初始化/使能中，不执行默认姿态斜坡
白色常亮  Standby
绿色常亮  Policy
```

## 按键

- `Y`：等待状态下执行当前所选启动模式；Standby 或 Policy 中保持
  末帧目标位置，在 3 秒内线性衰减 1~6 号的速度、力矩、Kp 和 Kd，归零后
  `MotorLock` 并回到等待状态。
- `X`：等待状态下切换“普通 Standby 启动/倒地自启 Policy”，青色/绿色呼吸
  分别表示当前选择；Standby/Policy 中仍为一键切换。进入 Policy 前执行机器门控，拒绝时
  保持 Standby。
- 方向键上 + `A` 持续约 0.25 秒：在正常或故障状态安全退出全部进程并失能电机。
- 程序停止后，方向键上 + `X` 持续约 0.25 秒并松开：重新执行完整启动和自检。
- `LB+RB` 维护标定入口本轮未接入；现有独立零点脚本仍可单独使用。

## 自动判定

- `can0` 必须为 UP，1~8 号必须返回有效反馈。
- IMU 必须在一个一秒窗口中严格大于 100 Hz；数值必须有限，最大
  断流不超过 200 ms。
- 手柄必须持续发布，1~6 反馈名称、长度和有限性必须正确；日常启动不检查
  模型 SHA 或腿关节初始位置，`--preflight-only` 仍执行模型完整性验收。
- 翼节点自动推进到 motor7=`+90°`/motor8=`-90°` 软件目标后进入保持；
  不验证实际角度误差或速度，但仍保留反馈超时、离线和停机边界检查。
- 进入 Standby 前，六维推理命令必须连续保持有限零值且频率正常。
- 倒地自启仍要求六维零动作和所有运行输入通过门控；`Y` 后只做电机初始化/使能，
  不运行默认姿态斜坡。电机收到 inference 的 Policy 模式公告后才接受第一帧策略。
  ACTIVE 后若翼、输入门控或 inference 切换失败，supervisor 会完整失能，不进入普通
  故障 Standby。

## 超时预算与故障区分

- 1–6 号进入 Standby 包含约 5.1 秒的串行初始化和 3 秒斜坡；supervisor
  等待服务响应 15 秒，为 CAN 操作和调度保留余量。
- 倒地自启包含同样约 5.1 秒的串行初始化，但没有 3 秒姿态斜坡；仍使用 15 秒
  服务响应期限。
- `*_SERVICE_UNAVAILABLE` 表示 ROS 服务在发现期限内不存在；
  `*_RESPONSE_TIMEOUT` 或 `STANDBY_TRANSITION_TIMEOUT` 表示服务已经发出请求，
  但节点没有在动作期限内返回；`*_REJECTED` 表示服务正常返回并明确拒绝。
- 机翼 RC 和推理模式切换是即时回调，响应期限为 5 秒；机翼启动定位
  使用独立的 45 秒状态等待。
- 正常 `Y` 软失能服务包含 3 秒卸力，supervisor 使用 8 秒响应期限。服务失败
  会改用立即硬失能并进入故障锁存；掉线、急停和进程退出不执行渐变。

## 故障显示

故障灯永久重复“红色 1 秒 → 分类色 1 秒 → 白色短闪子编号 → 熄灭 2 秒”。
分类色为：蓝=CAN/电机，紫=IMU，青=手柄/模型/设备，黄=翼，品红=ROS/推理，
橙=维护。日志同时记录稳定故障码和完整原因。故障锁存后不会自动重启；记下灯码后
长按方向键上 + `A` 退出，修复硬件，再长按方向键上 + `X` 并松开即可重新自检。

RGB 初始化或运行时失效按安全关键故障处理：不得继续使能电机。

## 开机自启

模板位于 `config/system/we11-deploy.service`。维护终端先执行一次
`./start_robot.sh --build`，再执行 `./config/system/install-we11-host.sh --enable`。
安装脚本只启用下次开机的手柄生命周期启动器，不会当场启动机器人。服务自动加载
`xpad` 并持续等待手柄；未连接时橙色呼吸，连接可用时绿色呼吸。长按方向键上 + `X` 并松开才会无参数运行
`start_robot.sh`。按键被接受后立即改为白色呼吸，并保持到 supervisor 完成 RGB
接管；正常启动时不再出现交接灭灯。即使 CAN/IMU 未接好，启动器仍可工作并让 supervisor 显示对应
故障码。机器人子程序不会自动重启，`WE11_AUTOSTART=1` 仍拒绝任何 `--build`。
