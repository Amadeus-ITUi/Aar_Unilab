# Lab 实机部署启动

日常入口是仓库根目录的 `start_robot.sh`。它启动唯一的 WE11 supervisor，所有
自检、灯光、手柄确认、子进程和安全退出都由 supervisor 统一管理。

## 准备与启动

首次使用或源码变化后，可在启动时显式要求构建：

```bash
cd /home/esd/Pheonix/Deploy
./start_robot.sh --build
```

日常启动默认不编译、不调用 `sudo`，也不等待终端输入：

```bash
./start_robot.sh
```

完整状态、灯光、按键和故障码见
[WE11_DAILY_STATE_MACHINE.md](WE11_DAILY_STATE_MACHINE.md)。

## 日常操作摘要

1. 橙色呼吸表示树莓派已开机但手柄未连接；绿色呼吸表示可按上+`X`。
2. 方向键上 + `X` 保持约 0.25 秒并松开，启动完整自检。
   按键接受后 RGB 会立即变为白色呼吸，并持续到 supervisor 接管，表示程序正在启动。
3. 翼节点自动下发 motor7=`+90°`/motor8=`-90°` 启动目标，不再按 `A`。
4. 自检完成后默认青色呼吸（普通启动）：此时 1~6 号失能且右摇杆可控机翼。
   扶稳机器人按 `Y`，白色闪烁表示姿态斜坡，白色常亮才是 Standby。
5. 如需倒地自启，在按 `Y` 前先按 `X`，灯变为绿色呼吸；确认机器人在地面且周围安全后按 `Y`，绿色闪烁期间只初始化/使能，不做默认姿态斜坡，随后直接进入 Policy。
6. 等待阶段可反复按 `X` 切换两种模式；运行阶段 `X` 切换 Standby/Policy。
   Standby 或 Policy 中按 `Y` 会在 3 秒内缓慢卸力，然后失能 1~6 号并回到青色等待态。
7. 方向键上 + `A` 保持约 0.25 秒，在正常或故障状态安全停止完整程序。

正常启动不会写入任何硬件零点。1~6 号维护设零仍使用独立脚本：

```bash
./set_zeros_1_6_joy.sh
```

## 开机自启边界

先在维护终端运行一次 `./start_robot.sh --build`，再执行
`./config/system/install-we11-host.sh --enable`。安装脚本不会立刻启动机器人，
只启用下次开机启动。仓库不保存 sudo 密码，服务以普通用户 `esd` 运行；开机
自动加载 `xpad` 并持续等待手柄。长按方向键上 + `X` 并松开后，无参数执行
`start_robot.sh`，并硬性禁止 `--build`。机器人子程序停止或故障后不会自动重启；
只有下一次“上 + X”长按并松开才会重新启动。生命周期启动器自身异常退出时由
systemd 恢复。

当前软件验收若没有 `can0`，预期行为是停在蓝色阶段并锁存 CAN 故障，且不能
启动任何电机控制节点。

翼启动阶段只判定软件目标轨迹已走到 `+90°/-90°`，不把实际角度误差或
速度作为放行条件；转换时的实际位置和速度会写入日志。
